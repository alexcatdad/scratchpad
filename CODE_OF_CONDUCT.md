# Code of Conduct

We want participation in this project to be a harassment-free experience for
everyone.

Be respectful and inclusive, accept constructive feedback gracefully, and focus
on what is best for the project and its users. Harassment, trolling, personal
attacks and publishing others' private information are not acceptable.

Maintainers may remove, edit or reject contributions, and block participants,
that violate this code. Report problems privately to the maintainer through
GitHub.

Adapted from the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

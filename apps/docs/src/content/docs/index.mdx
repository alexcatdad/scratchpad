## A home for the context between commits

<CardGrid>
  <Card title="Capture while you work" icon="pencil">
    Record a decision, a useful answer, or a failed investigation through a
    local MCP. Keep the original evidence, even as your understanding changes.
  </Card>
  <Card title="Pick up the thread" icon="magnifier">
    Give your next coding session a useful starting point: the project, its
    constraints, and the reasoning behind its current shape.
  </Card>
  <Card title="Keep it yours" icon="setting">
    A single-owner, self-hosted design with SQLite by default. AI is optional;
    your repository is never required to become the database.
  </Card>
  <Card title="Let knowledge evolve" icon="open-book">
    Separate captured history from curated knowledge. Corrections and
    replacements should add context without quietly rewriting the past.
  </Card>
</CardGrid>

## Small enough to start, durable enough to return to

Scratchpad connects local stdio MCP, a SQLite server, and a passkey-protected dashboard, with native import/export and optional repository mirrors. v0.2.0 adds [optional AI and semantic retrieval](/scratchpad/guides/ai/), private documents, and [PostgreSQL](/scratchpad/guides/postgresql/). v0.3.0 adds [native vectors, public GitHub profiles and generated API clients](/scratchpad/guides/optional-extensions/). Check [release validation](/scratchpad/guides/releases/) for publication and installation evidence.
